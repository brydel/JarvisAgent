# Carnet — facturation pour indépendants

Carnet est une application web de facturation.

## Ce que fait Carnet aujourd'hui

- Création d'une facture à partir de 3 modèles.
- Export des factures au format CSV, pour le comptable.
- Rappel de paiement envoyé par courriel quand une facture est en retard.
- Gratuit jusqu'à 5 clients ; au-delà, 9 € par mois.

## Ce que Carnet ne fait pas

- Pas d'application mobile.
- Pas de paiement en ligne.
- Pas de connexion bancaire.

# Nouveautés de la version 1.3

**Alertes de prix par courriel.** Choisissez un seuil pour un actif : nous vous écrivons dès qu'il est atteint,
même quand l'application est fermée.

**Export CSV du portefeuille.** Téléchargez vos positions en un clic pour les ouvrir dans votre tableur ou
les transmettre à votre comptable.

**Déconnexion sur mobile.** Le bouton de déconnexion fonctionne de nouveau sur téléphone.

Merci pour vos retours : ils ont guidé ces améliorations.

# Portefeuille

Suivi simple de portefeuille boursier.

## Installation

Prérequis : Python 3.11 ou plus.

1. Créez et activez un environnement virtuel, installez les dépendances, puis lancez l'application :

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m app
```

2. Si tout va bien, le terminal affiche : « Serveur prêt sur http://localhost:8000 ».

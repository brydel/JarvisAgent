# Préparer une intégration sur un poste

Cette procédure générique ne décrit pas un poste installé.

1. Relever en privé la branche, le commit et les modifications locales ; sauvegarder les fichiers remplacés et les données non suivies hors du dépôt.
2. Préparer l'intégration dans une copie distincte et comparer les outils existants au catalogue attendu.
3. Exécuter les tests locaux avec un état temporaire isolé ; consigner les échecs et prérequis manquants.
4. Faire valider séparément l'installation et les mandats avant toute modification d'un poste ou d'un nœud.

L'installation du client ne crée pas de mandat distant. Un mandat RedTeam reste distinct de l'audio.
Voir les [protocoles](VALIDATION_WSL.md) et la [politique des preuves](CONFIDENTIALITE.md).

# Reprendre les validations dans un environnement local

Lire AGENTS.md, les README et ARCHITECTURE.md. Examiner l'état Git et préserver les modifications.
Exécuter d'abord les tests avec moteurs factices et configuration temporaire.
Aucun accès SSH, inventaire matériel, installation, inférence ou changement de service n'est autorisé par ce document.
Définir ces opérations avec le propriétaire avant de les entreprendre.

Les [protocoles WSL](VALIDATION_WSL.md) et [Jetson](VALIDATION_JETSON.md) sont des modèles publics.
Stocker les observations réelles selon la [politique des preuves](CONFIDENTIALITE.md).

# Vision — Jarvis Next

Jarvis Next transforme une intention humaine en résultat **vérifié** : il planifie, délègue, exécute, supervise,
se souvient, s'évalue et s'améliore, en gardant le contexte, en appliquant les permissions par du code, en
coordonnant Claude Code et Codex, et en survivant aux interruptions. Son avantage n'est ni le nombre d'agents
affichés ni les animations : c'est la fiabilité de la transformation intention → résultat.

Le fondateur reste l'autorité finale sur les actions sensibles, l'argent, les engagements externes, les
identifiants, les changements critiques et la gouvernance de production.

## Décisions confirmées par le fondateur (non rediscutées sans bloqueur concret)

1. Plateforme combinée : système d'exploitation numérique personnel **et** usine logicielle.
2. Autonomie contrôlée : seul, le réversible à faible risque autorisé ; le sensible attend une autorisation explicite.
3. Organisation dynamique : rôles et sous-structures créés au besoin.
4. Intelligence persistante : base de connaissances reliée (projets, décisions, documents, expériences).
5. Jarvis Studio : un vrai environnement de travail interactif, pas un tableau de bord de chatbot.
6. Infrastructure progressive : portable ASUS (WSL2) d'abord, serveurs Linux ensuite.
7. Coûts maîtrisés : petit budget mensuel explicite au-delà des abonnements ; aucune inférence payante cachée.
8. Board événementiel : ajouter un contenu peut déclencher une analyse préautorisée à faible risque.
9. Deux fournisseurs : Claude Code et OpenAI Codex, aucun autre modèle sans autorisation.
10. Prêt pour le SaaS multi-tenant dès la conception ; lancement en installation mono-utilisateur.
11. Auto-amélioration contrôlée : seulement des changements étroits, réversibles, autorisés par une politique et
    une validation indépendantes.
12. Séparation : ce chantier concerne JarvisAgent seul (pas le projet Alexa / assistant vocal).
13. Déploiement hybride : **Jarvis Studio Cloud + exécutants locaux + exécutants hébergés** (décision d'architecture,
    pas une permission de provisionner des ressources payantes).
